# Web Technology Learnings 🌐

Welcome to **Web Technology Learnings**! This repository contains my practice programs, code examples, and learning exercises related to web development.

The goal of this repository is to build a strong foundation in web technologies through hands-on practice and consistent learning.

## 📚 Topics Covered

- **HTML (HyperText Markup Language)** — Page structure, semantic elements, forms, tables, multimedia, and links.
- **CSS (Cascading Style Sheets)** — Styling, colors, typography, borders, spacing, layouts, Flexbox, and responsive design.
- **JavaScript** — Fundamentals, variables, data types, operators, functions, DOM manipulation, and event handling.
- **Web Development Practice** — Layout creation, form design, website structure, and practical exercises.

##  Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sanketsgowdar22/Web-Technology-Learnings.git
   ```

2. Open the project folder:

   ```bash
   cd Web-Technology-Learnings
   ```

3. Open any HTML file in your preferred code editor, such as Visual Studio Code.

4. Run the HTML file in your browser to view the output.
